# Ideas Pipeline

## Lifecycle

```
inbox → developing → done
  └──→ parked ──→ developing → done
```

Folder = status. Moving a file between folders = status change.

## Idea File Template

```markdown
# Idea: [Title]

**Created**: YYYY-MM-DD
**Status**: inbox | developing | parked | done
**Category**: project | blog | tool | experiment | research
**Effort**: S | M | L | XL

## What
[One paragraph describing the idea]

## Why
[What problem does it solve? Who benefits?]

## Next Steps
- [ ] Step 1
- [ ] Step 2

## Notes
[Evolving thoughts, links, references — append over time]
```
